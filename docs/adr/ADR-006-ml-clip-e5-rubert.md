# ADR-006: ML Pipeline — CLIP + multilingual-e5 + ruBERT

**Дата:** 2026-03-01  
**Статус:** Accepted  
**Авторы:** CAT Team

---

## Контекст

CAT оценивает качество контента карточек товаров на маркетплейсах:
1. **Изображения:** соответствие эталонным фото бренда
2. **Описания и характеристики:** семантическое сходство с эталонным текстом
3. **Отзывы:** тональность (позитив/негатив/нейтраль)

Нужны модели с поддержкой русского языка, работающие локально (без внешних API).

## Рассматриваемые варианты

### Изображения
| Модель | Мультиязычность | Локально | Точность |
|--------|----------------|----------|----------|
| **CLIP (ViT-B/32) (выбран)** | ✅ | ✅ | Высокая |
| EfficientNet | ❌ (нет text) | ✅ | — |
| Google Vision API | — | ❌ | Высокая |

### Текст (описания)
| Модель | Русский | Локально | Размер |
|--------|---------|----------|--------|
| **multilingual-e5-base (выбран)** | ✅ | ✅ | 278M params |
| ruBERT-base | ✅ | ✅ | 180M params |
| OpenAI Embeddings API | ✅ | ❌ | — |

### Отзывы (тональность)
| Модель | Русский | Локально |
|--------|---------|----------|
| **rubert-base-cased-sentiment (выбран)** | ✅ (native) | ✅ |
| VADER | ❌ | ✅ |

## Решение

```python
# Итоговая формула оценки контента:
content_total = (
    0.40 × image_clip_cosine_sim      # CLIP: фото vs эталон
  + 0.35 × desc_e5_cosine_sim        # E5: описание vs эталон
  + 0.25 × comp_e5_cosine_sim        # E5: характеристики vs эталон
)
```

- Эталонные embeddings вычисляются **один раз при загрузке** и кешируются в Redis
- Инференс в батчах: CLIP batch=16, E5 batch=32, ruBERT batch=32
- Модели скачиваются в Docker volume при первом запуске (не в образе)

## Последствия

- **Положительные:** полностью offline, данные не покидают инфраструктуру, хорошее качество для русского языка
- **Отрицательные:** CLIP требует ~1GB RAM, E5 ~500MB — минимум 4GB RAM для processor-сервиса
- **При недостатке ресурсов:** CLIP можно заменить на `ViT-B/16` (меньше), E5 на `multilingual-e5-small`
