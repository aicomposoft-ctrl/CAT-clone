# CAT — Commerce Analytics Tool: Documentation

**CAT** — SaaS-платформа мониторинга онлайн-полки для FMCG-производителей и digital commerce агентств.
Ежедневный сбор данных на 110+ платформах, ML-оценка контента (CLIP + ruBERT), мониторинг дистрибуции и Excel-отчёты.
