# Интерфейс системы CAT

> Фронтенд находится в активной разработке. Этот раздел описывает спроектированный интерфейс на основе технических требований системы.

## Структура интерфейса

### Главная навигация (левая панель)

```
CAT Dashboard
├── Dashboard      — сводный дашборд
├── Content        — мониторинг контента
├── Stock          — дистрибуция план/факт
├── Reviews        — анализ отзывов
├── Prices         — мониторинг цен
├── Reports        — экспорт отчётов
└── Settings       — настройки системы
     ├── SKU Management
     ├── Platforms
     ├── Alerts
     └── Users (только admin)
```

**Технологии:**
- React 18 + TypeScript
- Ant Design 5.x (компоненты, темизация)
- Apache ECharts 5.x (графики и диаграммы)
- React Query (серверное состояние)
- Zustand (клиентское состояние)

## Основные экраны

### Dashboard (главный дашборд)

Виджеты:
- **Content Score по платформам** — bar chart, топ-5 проблемных SKU
- **Дистрибуция** — gauge chart, средний % по всем сетям
- **Отзывы** — pie chart, позитив/негатив/нейтрал за последние 7 дней
- **Алерты** — карточки последних неотработанных алертов
- **Статус скрапинга** — таблица: платформа / последний запуск / статус / кол-во SKU

## Элементы управления

### Цветовая схема score

| Значение | Цвет | Ant Design token |
|---------|------|-----------------|
| ≥ 80% | Зелёный | `success` |
| 50–79% | Жёлтый | `warning` |
| < 50% | Красный | `error` |

### Пагинация таблиц

Все таблицы используют серверную пагинацию: 50 строк по умолчанию. `rowKey` — всегда `id` (UUID), не индекс массива.

### Уведомления

Алерты из системы отображаются в виде Ant Design `Notification` в правом верхнем углу. Центр уведомлений доступен через иконку колокольчика в header.

### Экспорт

Кнопка **Export** в каждом разделе открывает Ant Design `Modal` с выбором:
- Диапазон дат
- Бренды / платформы
- Формат (xlsx, всегда)

### Адаптивность

Интерфейс оптимизирован для десктопа (1280px+). На мобильных устройствах основные таблицы переходят в горизонтальный скролл.
