# Руководство пользователя CAT

## Начало работы

### Первый вход

1. Перейдите по адресу `https://your-domain.ru`
2. Введите email и пароль, полученные от администратора
3. После входа вы попадёте на главный дашборд

### Смена пароля

Настройки → Профиль → Изменить пароль.

## Раздел: Content (Мониторинг контента)

### Таблица content score

Основной экран раздела показывает таблицу со столбцами:

| Столбец | Описание |
|---------|----------|
| Платформа | Маркетплейс или магазин |
| Бренд | Ваш бренд или конкурент |
| Артикул | Артикул товара |
| SKU Name | Наименование |
| Content Total | Итоговый балл 0–100% |
| Image:Front | Соответствие фото эталону |
| Description | Соответствие описания |
| Composition | Соответствие состава |
| URL | Ссылка на карточку |

**Цветовая кодировка:**
- Зелёный (≥ 80%) — норма
- Жёлтый (50–79%) — требует внимания
- Красный (< 50%) — критично, нужно исправить

### Как читать результаты

**Content Total** рассчитывается по формуле:
```
Content Total = 40% × Image Score + 35% × Description Score + 25% × Composition Score
```

Алгоритм сравнивает загруженные маркетплейсом изображения и тексты с вашими эталонными материалами через ML-embeddings (CLIP для изображений, multilingual-e5 для текста).

### Детальный просмотр SKU

Нажмите на строку в таблице, чтобы открыть панель детального сравнения:
- Визуальное сравнение: фото с маркетплейса vs эталон
- Diff описания: отличия от эталонного текста выделены
- График истории score за 30 дней
- Прямая ссылка на карточку

### Фильтрация и сортировка

- Фильтры: бренд, платформа, диапазон дат, диапазон score
- Сортировка по любому столбцу — нажмите на заголовок
- Чтобы найти самые проблемные карточки: отсортируйте по **Content Total** по возрастанию

### Экспорт отчёта Content

1. Нажмите **Export → Content Report**
2. Выберите диапазон дат и бренды
3. Скачайте `Content_Report_YYYY-MM-DD.xlsx`

Файл содержит два листа:
- **Total** — сводный балл по платформам
- **Score card** — детальная таблица по каждому SKU × платформа

## Раздел: Stock (Дистрибуция)

### Загрузка плана дистрибуции

1. Раздел Stock → **Управление планом**
2. Нажмите **Загрузить план**
3. Загрузите CSV/Excel файл со столбцами:
   - Площадка, Группа, Название карточки, Кол-во ТТ (план)
4. Подтверждение: «План загружен для N SKU по M сетям»

### Дашборд дистрибуции

Таблица **По сети** показывает план/факт по каждой торговой сети:

| Столбец | Описание |
|---------|----------|
| Площадка | Торговая сеть (Ритейлер, Лента и т.д.) |
| Группа | Товарная группа (Фреш, МКИ, Заморозка) |
| SKU | Наименование |
| ТТ план | Плановое количество торговых точек |
| ТТ факт | Фактическое количество ТТ с наличием |
| Дистрибуция % | Факт / План × 100% |

SKU с дистрибуцией < 80% подсвечены красным.

### Детализация по городам

Нажмите на SKU → откроется таблица с разбивкой по городам и неделям (4 недели назад).

### Доля в ассортименте

Вкладка **Доля в асс-те** показывает долю вашего бренда в ассортименте магазина по городам.

### Экспорт Stock Report

**Export → Stock Report** — файл `Stock_Report_YYYY-MM-DD.xlsx` с 7 листами:
- План Факт по сети
- Все SKU категория_бренд
- SKU на ДС по городам
- Доля в асс-те по городам
- SKU по адресам
- План_Факт ТОП города
- SKU на ТТ

## Раздел: Reviews (Отзывы)

### Общая аналитика

Вкладка **Тотал по брендам** показывает сводку сентимента по брендам:

| Бренд | Компания | Доля негатива | Доля позитива |
|-------|---------|---------------|---------------|
| Ваш бренд | Клиент | 22% | 65% |
| Конкурент А | Конкурент | 38% | 42% |

Сентимент анализируется ML-моделью (ruBERT), классифицируя каждый отзыв как positive / negative / neutral.

### Тексты отзывов

Фильтруемый список всех отзывов с полями:
- Маркетплейс, Категория, Бренд, SKU
- Текст отзыва, Рейтинг (1–5 звёзд), Сентимент, Дата

Фильтры: бренд, маркетплейс, категория, сентимент, диапазон дат.

### Экспорт Reviews Report

**Export → Reviews Report** — Excel с 4 листами:
- Сводная
- Тотал по брендам
- Тотал по брендам и категориям
- Тексты отзывов

## Раздел: Prices (Цены)

### Мониторинг цен

Таблица с историей цен по каждому SKU × платформа × дата. Можно сравнить свою цену с ценами конкурентов на одной платформе.

Промо-события и скидки подсвечены.

### Настройка порогов алертов по ценам

Настройки → Алерты → Добавить правило:
- Тип: `price_change` или `competitor_promo`
- Порог: например, 10% изменение
- Email-получатели

## Раздел: Settings (Настройки)

### Управление SKU

**Settings → SKU Management:**
- Добавить SKU вручную
- Массовая загрузка через CSV (до 10 000 строк)
- Загрузить эталонное изображение для каждого SKU
- Задать эталонное описание и состав

### Загрузка эталонных материалов

1. Settings → SKU → нажмите на артикул
2. Секция **Reference materials**:
   - Image:Front — загрузите JPG/PNG (эталонное фото фасада)
   - Description — вставьте эталонное описание (до 5 000 символов)
   - Composition — вставьте эталонный состав

> После загрузки эталонов система автоматически пересчитает content score при следующем цикле сбора (ночью в 02:00).

## Часто задаваемые вопросы

**Как часто обновляются данные?**
Контент и отзывы — ежедневно в 02:00. Цены — каждые 4 часа.

**Почему content score низкий, хотя карточка выглядит правильно?**
Возможные причины: устаревший эталон (загрузите новый), платформа изменила формат отображения. Откройте детальный просмотр SKU и проверьте side-by-side сравнение.

**Как получить алерт о падении score?**
Settings → Alerts → создайте правило с типом `content_drop` и укажите пороговое значение (например, 70%).

**Данные доступны только по моей организации?**
Да. Система мультитенантная — каждый клиент видит только свои данные.

**Сколько SKU поддерживается?**
MVP: до 10 000 SKU. v1.0: до 100 000 SKU.

**Как добавить новую платформу?**
Обратитесь к администратору — добавление платформ требует роль `admin`.
